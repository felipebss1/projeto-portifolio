# Portfólio Pessoal - Bruno Soares

Este projeto é um website de portfólio pessoal desenvolvido para apresentar minha trajetória, habilidades técnicas e os projetos práticos realizados durante meus estudos de desenvolvimento web. O objetivo é centralizar minhas conquistas e facilitar o acesso ao meu trabalho e redes profissionais.

## 🚀 Funcionalidades

- **Tema Claro/Escuro:** Alternância dinâmica de tema com persistência de preferência do usuário utilizando `localStorage`.
- **Navegação Fluida:** Menu fixo com ícones intuitivos e sistema de scroll suave para facilitar a leitura entre as seções.
- **Showcase de Projetos:** Galeria detalhada utilizando elementos HTML5 `<details>` para descrições expansíveis, mantendo a interface limpa e organizada.
- **Responsividade:** Design adaptável para diferentes tamanhos de tela, garantindo uma boa experiência em dispositivos móveis e desktops.
- **Indicadores de Habilidade:** Visualização gráfica do nível de proficiência em tecnologias como HTML5, CSS3 e JavaScript.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica e acessível do conteúdo.
- **CSS3:** Estilização moderna, uso de variáveis para temas e layouts flexíveis.
- **JavaScript (Vanilla):** Lógica para manipulação do DOM, persistência de dados no navegador e comportamento de scroll.
- **FontAwesome:** Biblioteca de ícones para navegação, habilidades e redes sociais.

## 📂 Estrutura do Projeto

O projeto segue uma estrutura organizada para facilitar a manutenção:

- `index.html`: Arquivo principal contendo toda a estrutura semântica.
- `estilos/`: Diretório com as folhas de estilo (estilo base e adaptações responsivas).
- `scripts/`: Lógica JavaScript para interatividade.
- `imagens/`: Assets visuais e miniaturas dos projetos realizados.

## 📦 Como Visualizar

Para visualizar o projeto localmente:

1. Clone o repositório:
   ```bash
   git clone https://github.com/felipebss1/portfolio.git
   ```
2. Abra o arquivo `index.html` em seu navegador de preferência.
