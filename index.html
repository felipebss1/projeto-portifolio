Projeto de Vídeos

Este é um projeto de portal de vídeos simples desenvolvido para praticar conceitos fundamentais de HTML e CSS. Seu foco está na criação de uma estrutura com múltiplas páginas interligadas por links internos, incorporação de vídeos do YouTube por meio de iframes, aplicação de estilos básicos com CSS e organização dos arquivos em diretórios. Projeto Cordel

Projeto construído para treinar efeito paralax em imagens.

Saiba mais...

Este é um projeto web desenvolvido para criar uma experiência de leitura visualmente atraente de um poema de cordel. Seu principal objetivo é praticar o efeito Parallax com CSS, utilizando imagens de fundo fixas para gerar sensação de profundidade durante a rolagem da página. Além disso, o projeto explora o uso de HTML5 semântico, tipografia personalizada, estilização de textos e manipulação de imagens de fundo, proporcionando uma leitura dinâmica e uma apresentação visual mais rica e moderna.

Projeto Android

Saiba mais...

Este é um projeto de desenvolvimento web que consiste na criação de uma página de artigo responsiva sobre a história do mascote do Android. Seu objetivo é consolidar conceitos avançados de HTML5 semântico, CSS3, responsividade com a tag <picture>, integração de mídias como vídeos do YouTube e boas práticas de experiência do usuário. Projeto Links

Projeto construído para treinar redirecionamento de páginas usando a tag <a>.

Saiba mais...

O projeto links é uma aplicação web inspirada em uma árvore de links, que simula a interface de um smartphone para exibir conteúdos de diferentes redes sociais. Seu principal objetivo é praticar a navegação com iframes e targets, carregando páginas internas dentro de uma tela simulada. Além disso, o projeto explora a modularização de conteúdo, a estilização de interfaces que reproduzem dispositivos móveis e a criação de uma experiência centralizada para acesso a redes sociais, reforçando conceitos de organização, usabilidade e navegação em HTML e CSS.

O projeto login consiste no desenvolvimento de uma página de autenticação moderna e responsiva, voltada para a captura segura de credenciais de usuário.
